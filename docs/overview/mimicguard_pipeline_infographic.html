The MimicGuard experiment pipeline, step by step

Can an autoencoder trained only on normal fiber-wireless channel data spot an eavesdropper that imitates the channel, and how does it compare with classical detectors as the imitation gets better? Twelve steps; the first four are built and checked.

Done Next Planned Normal signal Attacker

    Freeze the design

    Before any detector was written, every condition the study will test was fixed, so later results cannot be tuned to look good.

    • SNR at the wireless receiver: 0, 5, 10, 15, 20, 25, 30 dB (7 levels).
    • Fading: none, Rician (K = 5), Rayleigh.
    • Attacker fidelity α: 0, 0.25, 0.5, 0.75, 1. At 0 the tap leaves its full footprint; at 1 it hides all of it.
    • 10 seeds per cell. 7 × 3 × 5 = 105 cells, so 1,050 cell-seed runs.
    • Six features per window and a fixed attacker model (both shown in steps 3 and 4).
    • Data split 60 / 20 / 20 by channel realisation, so no realisation appears in two sets.
    Producesexperiments/configs/base.yaml: the frozen grid and every model parameter. Values marked "assumption" there still need a citation.

    Attacker model

    The eavesdropper taps the fiber output, just before the handover. A real tap leaves a footprint on the signal. The fidelity α is how much of that footprint the attacker manages to hide.

    Constellation effects are enlarged so they are visible; the real sizes are a 10% power drop, noise 30 dB below the signal and a 0.03 echo.

    0.00 Identical to normal
    0 → 0.5restore power
    0.5 → 0.75match the noise
    0.75 → 1remove the echo
    Drag the slider to set α yourself. Each part fades linearly over its own range, in order.
    • Mean: the tap removes 10% of the optical power. The handover has a fixed gain set from the untapped link, so this shows as a power drop.
    • Variance: insertion noise at 30 dB SNR relative to the tapped signal.
    • Higher-order shape: a one-symbol echo with relative amplitude 0.03.
    • At α = 1 the attacked signal is statistically the same as normal, so no detector should beat chance there.
    Producessrc/mimicguard/attacker.py. Footprint sizes chosen by the calibration scan experiments/m2_footprint_check.py --scan → results/m2_footprint/scan.json.

    Features and dataset

    Each 256-symbol window becomes six numbers. These feature vectors are all that any detector will see.

    Right: the footprint check. For each α, the best AUC any single feature reaches when separating attacked windows from the normal windows before onset (seed 0, 10 test streams). Nothing is trained here. Data: results/m2_footprint/auc.json.

    • No fading, 20 dB: best AUC 1.00, 1.00, 0.89, 0.74, 0.51 across α. Detectability steps down as each footprint part is hidden.
    • Fading hides the power drop (Rayleigh power AUC 0.53 even at α = 0); amplitude variance carries most of the signal there.
    • Rayleigh at 5 dB is near chance at every α: a candidate regime where every detector fails. INFERRED
    • At α = 1 every feature sits within about 0.03 of 0.5 in every cell.
    • Fix 1: absolute pilot phase gave AUC 0.64 at α = 1 because laser phase noise makes it drift over time. Replaced by the window-to-window phase change, now at chance.
    • Fix 2: footprint sizes calibrated (noise 25 / 30 / 35 dB × echo 0.02 / 0.03 / 0.05); 30 dB and 0.03 give the clean step-down above.
    Producessrc/mimicguard/features.py, dataset.py. Check: experiments/m2_footprint_check.py → results/m2_footprint/auc.json.

    Classical detectors

    Six standard anomaly detectors learn from normal windows only. Each gets one alarm threshold, set so that 1% of normal validation windows trigger it.

    Score histogram is schematic; no detector has been run yet.

    • Energy and CUSUM work on the power feature over time; PCA residual, one-class SVM, Isolation Forest and LOF work on the six-feature vector.
    • Training uses the 30 train realisations, normal data only. The attacker is never seen during training.
    • Threshold: the 99th percentile of each detector's scores on the 10 normal validation realisations.
    ProducesPlanned: detector code in src/mimicguard/, a run script in experiments/, trained models, thresholds and test scores in results/.

    Evaluation

    One fixed set of measurements for every detector, grid cell and seed, plus two baselines that show whether a number means anything.

    All three panels are schematic; no results exist yet.

    • AUC: how well scores separate attacked from normal windows, over all thresholds.
    • Detection rate at 1% false alarms: the share of attacked windows flagged with the fixed threshold.
    • Delay: windows from attack onset (window 100) to the first alarm.
    • Seeds: mean and spread over 10 seeds; paired tests compare detectors on the same seeds.
    • Baselines: random scores (AUC 0.5) and a plain power threshold.
    ProducesPlanned: metrics code in src/mimicguard/; one metrics table per cell, detector and seed in results/.

    Autoencoder

    An autoencoder learns to squeeze the six features through a small bottleneck and rebuild them. It only ever sees normal windows, so windows it cannot rebuild well are suspicious.

    Schematic. Layer sizes and feature values are illustrative; the latent size is one of the ablations.

    • Trained on normal train windows; threshold set the same way as the classical detectors (1% false alarms on validation).
    • Anomaly score = reconstruction error between the input features and the rebuilt ones.
    ProducesPlanned: autoencoder code in src/mimicguard/, a training script in experiments/, trained models and validation scores in results/.

    Go / no-go

    A planned checkpoint: compare the autoencoder with the best classical detector, cell by cell. The paper has a result either way.

    • If yes: report where it wins, by how much, and against which footprint part.
    • If no: report that simple detectors are enough where anything works.
    • Both outcomes map where simple detectors are enough and where all of them fail. The footprint check already points at Rayleigh 5 dB as a fail region. INFERRED
